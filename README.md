## 交互

- 左右滑动 / 点击箭头翻页，键盘 `←` `→` 也可
- 底部「目录」打开全屏目录，可跳转任意页
- 支持深链接：`?p=7` 直达第 7 页
- 自动适配手机安全区与 `100dvh`

## 本地预览

直接用浏览器打开 `index.html` 即可；也可以起一个静态服务：

```bash
python -m http.server 8099
# 访问 http://127.0.0.1:8099
```

## 部署

本仓库只托管源码。Gitee Pages 免费服务已停止，若要公网访问，推荐把本目录上传到静态托管平台：

- Cloudflare Pages（拖拽上传，得到 `xxx.pages.dev`）
- 腾讯云 CloudBase 静态托管（国内访问更稳定）
- 任意自有服务器 / OSS + CDN
